Using These Resources

I've chosen to use a GitHub project because it provides facilities to author, publish and maintain source materials. Unlike some other repositories for OER it provides everything needed for creating adapted versions of my materials by others.

How?

If you feel that the version of the work I've published on this web site is all you need then simply use it where it is.

Please bear in mind that these works will be continuously updated. If you are interested you can track changes in the GitHub project.

If you want to adapt material here for your own purposes I suggest you-

  • Sign up to GitHub
  • Fork my project (GitHub help explains what that means)
  • Make edits to the text within your forked Github project thereby easily satisfying the license requirement to re-release modified versions under the same license.
  • Download your adapted text and convert to the format most appropriate for sharing with your learners or workshop participants. (Remembering to include proper attribution including a link to this site and a copy of the license name and logos.)
  • Upload those final delivery versions to the releases section of your GitHub project.
  • Use the discussion tool in my project to communicate with me and other interested people.
  • I will be able to find your modified versions and you will be able to find the versions that are based on yours if everyone works in GitHub.
  • It is good practice to maintain a clone of your GitHub project on your own computer/storage medium in case GitHub suffers a catastrophic failure or you simply decide to switch to another provider.
